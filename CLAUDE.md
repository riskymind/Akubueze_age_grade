# Akubueze

The Akubueze(Age Grade Association Management System) is a private membership-based web application built with Next.js for managing age grade associations, meetings, attendance, payments, and member activities.

## Commands

- **Dev server**: `npm run dev` (runs on http://localhost:3000)
- **Build**: `npm run build`
- **Production server**: `npm run start`
- **Lint**: `npm run lint`
- **Test**: `npm run test` (single run)
- **Test watch**: `npm run test:watch`
