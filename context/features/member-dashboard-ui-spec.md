# Member Dashboard Data Specification

## Overview

The member dashboard main content area (right side) displays real-time data fetched from the database.

This specification defines:

- Member dashboard sections
- Database data requirements
- API response structure
- Query expectations
- Role visibility
- Refresh strategy
- Empty states
- Performance expectations

---

# Payment Layout Structure

The payment main content area contains:

1. Welcome Header
2. Statistics Cards
3. Next Meeting
4. User Profile
5. Recent Payment
6. Association Announcement
