# Members Data Specification

## Overview

The members main content area (right side) displays real-time data fetched from the database.

This specification defines:

- Members sections
- Database data requirements
- API response structure
- Query expectations
- Role visibility
- Refresh strategy
- Empty states
- Performance expectations
- 300ms debounce
